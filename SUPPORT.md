# Assistance Relecture

Pour un problème d’installation, une question sur l’utilisation ou une suggestion concernant Relecture pour ordinateur ou Relecture Texte, ouvrez un sujet dans le [suivi des demandes](https://github.com/NathanOtano/Relecture/issues).

Indiquez l’édition, la version si elle est affichée, les étapes suivies et le résultat attendu. Utilisez un exemple fictif pour illustrer le problème. Gardez les textes confidentiels, les adresses et les liens d’invitation hors des sujets publics.

Pour un problème de sécurité, suivez les [consignes de signalement](SECURITY.md).
